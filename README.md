# Movia

Легковесное нативное приложение для macOS на базе Apple Silicon, предназначенное для создания высококачественного кинематографичного замедления (Slow Motion) с аппаратным ускорением VideoToolbox и Neural Engine.

## Возможности

- Аппаратное ускорение на Apple Silicon: энергоэффективная обработка с контролем температуры под безвентиляторные Mac (MacBook Air M1/M2/M3) с минимальным потреблением оперативной памяти (до 300 МБ).
- Точный таймлайн: масштабирование шкалы от 1.0x до 8.0x с засечками до десятых долей секунды и миллисекундный ввод точек In, Out и Длительности.
- Инструменты монтажа: обрезка, ножницы (Split / Trim) и покадровая дорожка миниатюр (filmstrip).
- Экспорт выбранного фрагмента: мгновенная обрезка и сохранение только замедленного участка без необходимости рендерить весь исходный файл.
- Устранение мерцания и стробирования: единый цветовой конвейер Rec.709 и монотонная генерация меток времени PTS.
- Адаптивный битрейт: сохранение исходного качества и битрейта видео без необоснованного раздувания размера файла.
- Поддерживаемые форматы экспорта: H.264 (MP4), H.265 (HEVC), Apple ProRes 422 и Apple ProRes 422 HQ.

## Системные требования

- macOS 14.0 (Sonoma) или новее.
- Архитектура Apple Silicon (M1 / M2 / M3 / M4).
